# Getting help

- **How do I…?** Start with the [README](README.md) and the [detailed guide](docs/GUIDE.md). Ziggy One's own agent,
  ZiggyBoss, can also answer questions about the code and adapt it for you.
- **Something is broken:** open a [bug report](https://github.com/molory/ziggy-one/issues/new?template=bug_report.yml)
  with your OS, Python, Claude Code and browser versions.
- **An idea:** open a [feature request](https://github.com/molory/ziggy-one/issues/new?template=feature_request.yml).
- **A security issue:** never in a public issue, see [SECURITY.md](SECURITY.md).

Ziggy One is maintained on a best-effort basis by volunteers. It is an independent project: for problems with
Claude Code itself or your Claude account, contact Anthropic.
